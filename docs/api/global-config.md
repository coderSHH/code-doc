# 全局配置项

| 配置项                  | 类型       | 默认值             | 描述                                                                 |
|------------------------|------------|--------------------|----------------------------------------------------------------------|
| `LAYOUT_TYPE`          | LayoutType | `"horizontal"`     | 设置默认布局模式                                                     |
| `LOGIN_VER_TYPE`       | LoginVerType | `"captcha"`      | 设置默认登录验证码类型                                               |
| `HOME_URL`             | string     | `"/home"`          | 设置首页地址                                                         |
| `LOGIN_URL`            | string     | `"/login"`         | 设置登录页地址                                                       |
| `DEFAULT_PRIMARY_COLOR`| string     | `"#156ffc"`        | 设置默认主题颜色                                                     |
| `GREY_THEME`           | boolean    | `false`            | 是否开启灰色模式                                                     |
| `THEME_MODEL`          | string     | `"light"`          | 设置暗黑/亮白模式（`dark` 或 `light`）                               |
| ...                    | ...        | ...                | ...                                                                |
