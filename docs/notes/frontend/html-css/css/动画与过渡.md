# 动画与过渡

### **使用 CSS 实现卡片翻转的动画**

**知识概述**

* 使用 **3D 变换（**`transform`**）** 和 **过渡（**`transition`**）** 实现翻转效果。

* 关键属性：`perspective`（设置透视）、`backface-visibility`（隐藏背面）、`rotateY`（绕 Y 轴旋转）。

**答案详解**

```plain
<div class="card-container">
  <div class="card front">正面</div>
  <div class="card back">背面</div>
</div>
.card-container {
  width: 200px;
  height: 200px;
  perspective: 1000px; /* 设置透视距离 */
}

.card {
  width: 100%;
  height: 100%;
  position: absolute;
  backface-visibility: hidden; /* 隐藏背面 */
  transition: transform 0.5s ease;
}

.front {
  background: lightblue;
  transform: rotateY(0deg);
}

.back {
  background: lightgreen;
  transform: rotateY(180deg);
}

.card-container:hover .front {
  transform: rotateY(180deg);
}

.card-container:hover .back {
  transform: rotateY(0deg);
}
```
**实战场景**
* 商品详情页的卡片翻转查看功能。

* 教育类网页的翻转卡片展示知识点。


---
### **CSS 中的 animation、transition、transform 的区别？各自的属性？**

* `animation`：复杂动画，支持关键帧。

* `transition`：简单属性过渡，依赖事件（如 `hover`）。

* `transform`：几何变换（旋转、缩放等），不触发回流。


---
### **在解决动画卡顿问题时，会引导硬件加速，那么硬件加速的原理是什么？**

* **硬件加速**：通过 GPU 渲染动画，减少 CPU 负载。

* **触发方式**：使用 `transform`、`opacity`、`will-change`。


---
### **CSS 动画和 JS 实现的动画各自的优缺点？**

* **CSS 动画**：

   * **优点**：简单、性能好（GPU 加速）。

   * **缺点**：控制粒度低。

* **JS 动画**：

   * **优点**：灵活、可监听事件。

   * **缺点**：性能依赖代码优化。


---
### **前端实现动画有哪些方式？**

* **CSS 动画**：`@keyframes`、`transition`、`animation`，性能好但控制粒度低。

* **JS 动画**：`requestAnimationFrame`、`setInterval`或 `setTimeout`，灵活但需手动控制。

* **第三方库**：GSAP、Anime.js。


---
### **使用 CSS 实现一个无限循环动画**

```css
@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
.infinite-spin {
  animation: spin 2s linear infinite;
}
```
