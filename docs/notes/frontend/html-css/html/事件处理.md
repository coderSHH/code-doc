
### 如何阻止事件冒泡？

* 方法：`event.stopPropagation()`

示例：

```plain
child.addEventListener('click', (e) => {
  e.stopPropagation(); // 阻止冒泡到父元素
});
```

### 如何阻止事件默认行为？

* 方法：`event.preventDefault()`

示例：

```plain
form.addEventListener('submit', (e) => {
  e.preventDefault(); // 阻止表单提交
});
```

### 如何通过HTML实现表单验证？请列举至少三种验证方式，并说明其优缺点。

*  HTML5原生属性（`required`、`pattern`、`minlength`等）：

   * 优点：简单轻量，无需JS，兼容现代浏览器。

   * 缺点：功能有限，需配合JS增强复杂验证。

   * 示例：`&lt;input type="email" required&gt;`。

* JavaScript手动校验输入值（如邮箱格式、密码复杂度）。

   * 优点：灵活，可自定义逻辑，定制错误提示等。

   * 缺点：增加代码量，需处理跨浏览器兼容性。

   * 示例：`if (email.value.indexOf('@') === -1) alert('邮箱格式错误')`。

* 第三方库（如Validation.js）：

   * 快速集成复杂规则（如异步验证）。

   * 优点：封装完善，功能丰富，减少重复代码节省开发时间。

   * 缺点：依赖外部库，性能开销。

### 如何使用事件监听器处理键盘事件？

* 方法：监听`keydown`/`keyup`事件，通过`event.key`或`event.keyCode`判断按键。

示例：

```plain
document.addEventListener('keydown', (e) => {
  if (e.key === 'Enter') console.log('回车键被按下');
});
```

### 如何使用自定义数据属性在事件中传递数据？

* 方法：用`data-*`属性存储数据，通过`dataset`获取。

示例：

```plain
<div data-id="123" onclick="handleClick(this)">点击我</div>

    console.log(el.dataset.id); // 输出123
  }
```

#### 7. 事件冒泡和事件捕获的区别？

* 冒泡：事件从最内层元素向外层传播（默认阶段）。

* 捕获：事件从外层元素向内层传播（需设置`useCapture: true`）。

示例：

```plain
javascript
深色版本

// 捕获阶段
element.addEventListener('click', func, true);
```

---

#### 8. 事件委托是什么？

* 定义：通过父元素监听子元素事件，利用事件冒泡。

* 优点：减少事件监听器数量，动态新增元素也能触发。

示例：

```plain
javascript
深色版本

// 父元素监听所有子项点击
ul.addEventListener('click', (e) => {
  if (e.target.tagName === 'LI') {
    console.log(e.target.textContent);
  }
});
```

---

#### 9. 如何移除事件监听器？

* 要求：函数名、事件类型、捕获参数需与注册时一致。

示例：

```plain
javascript
深色版本

const handler = () => console.log('事件');
btn.addEventListener('click', handler);
btn.removeEventListener('click', handler); // 移除
```

#### 11. 如何处理多个按钮的点击事件？

* 方法：

   * 事件委托：父元素监听所有子按钮。

   * 循环绑定：通过类名批量添加事件。

示例：

```plain
javascript
深色版本

// 事件委托
const btnContainer = document.querySelector('.btns');
btnContainer.addEventListener('click', (e) => {
  if (e.target.classList.contains('btn')) {
    console.log(e.target.dataset.action);
  }
});
```

#### 14. 在事件处理中使用箭头函数？

```plain
});
```
