# Router

Vue Router 是官方为 Vue.js 提供的路由管理器。它能够让你构建单页面应用（SPA）变得更加简单。Vue Router 使用 HTML5 的 History API 来实现前端路由，从而允许你在不重新加载页面的情况下切换视图。

核心概念

-   路由（Route）
    路由是 URL 中的路径与组件之间的映射关系。每个路由都会映射到一个组件。

-   路由器（Router）
    路由器是管理路由的容器。它包含了一系列的路由规则，并负责根据当前的 URL 来显示相应的组件。

-   视图（View）
    视图是路由渲染的组件所占据的位置。通常，我们会在 Vue 根实例中包含一个 <router-view/> 组件，用于显示当前路由所对应的组件。

## 项目封装 router

### 路由参数配置简介

| 参数             | 描述                                                                     |
| :--------------- | :----------------------------------------------------------------------- |
| path             | 路由菜单访问路径                                                         |
| name             | 路由 name (对应页面组件 name, 可用作 KeepAlive 缓存标识 && 按钮权限筛选) |
| redirect         | 路由重定向地址                                                           |
| component        | 视图文件路径                                                             |
| meta             | 路由菜单元信息                                                           |
| meta.icon        | 菜单和面包屑对应的图标                                                   |
| meta.title       | 路由标题 (用作 document.title / 菜单的名称)                              |
| meta.activeMenu  | 当前路由为详情页时，需要高亮的菜单                                       |
| meta.isLink      | 路由外链时填写的访问地址                                                 |
| meta.isHide      | 是否在菜单中隐藏 (通常列表详情页需要隐藏)                                |
| meta.isFull      | 菜单是否全屏 (示例：数据大屏页面)                                        |
| meta.isAffix     | 菜单是否固定在标签页中 (首页通常是固定项)                                |
| meta.isKeepAlive | 当前路由是否缓存                                                         |

### 路由拦截处理

-   判断是访问，有 Token 就在当前页面，没有 Token 重置路由到登陆页
-   判断访问页面是否在路由白名单地址(静态路由)中，如果存在直接放行
-   如果没有菜单列表，就重新请求菜单列表并添加动态路由
